# Contributing

SyzAgent welcomes contributions related to documentation, reproducible examples, fuzzing workflow improvements, and agent-loop evaluation.

Good first contributions:
- Improve setup documentation
- Add example target configurations
- Add crash log samples
- Improve triage report formatting
- Report setup or environment issues

Please avoid submitting exploit-oriented payloads or unsafe proof-of-concept code. This project is focused on defensive security research, fuzzing workflow automation, and responsible vulnerability analysis.
